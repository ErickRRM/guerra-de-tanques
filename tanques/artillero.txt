# Artillero — torreta: dispara a los cuatro lados y guarda los misiles para
# cuando el radar ve a alguien en línea. AMT sin IF: con o sin blanco gasta
# el mismo turno, y así siempre dispara.
IF RADAR(N) > 0 THEN MISIL(N)
AMT(N)
AMT(E)
IF RADAR(S) > 0 THEN MISIL(S)
AMT(S)
AMT(O)
IF VIDA < 60 THEN ESCUDO
IF VIDA < 40 THEN REPARAR
