# Minador — avanza hacia el este lanzando minas a las esquinas de atrás.
# Las minas caen siempre en la columna de la que viene, y cada vuelta
# termina una columna más al este: nunca vuelve atrás, así que no pisa sus
# propias minas. Al llegar a la pared oriental se queda ahí vigilando.
MINA(NO)
AMT(O)
MOV(S)
MINA(SO)
AMT(S)
MOV(E)
IF RADAR(E) > 0 THEN MISIL(E)
AMT(E)
MOV(N)
AMT(N)
IF V < 50 THEN ESCUDO
